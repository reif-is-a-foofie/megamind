# MORNING BRIEF PROMPT

You are starting a new session. Run the morning brief.

## Steps

1. Query memory for:
   - Current state of each quadrant (what's been done, what's lagging)
   - In-flight work (startup, projects, ongoing threads)
   - Active people threads (who I owe a call, what's ongoing)
   - Any patterns relevant to today

2. Check live sources for:
   - New email requiring attention
   - Today's calendar
   - Anything that moved overnight

3. Synthesize:
   - Which quadrant is most underserved right now?
   - What is the single highest-leverage action I can take today?
   - What can you handle without me?
   - What should I know but not act on yet?

## Output format

```
DATE / TIME

FOCUS: [quadrant]
ACTION: [one specific next action — concrete, doable today]
WHY: [one sentence — why this is the right thing right now]

BRIEF:
- [bullet: what happened overnight that matters]
- [bullet: what's on the calendar]
- [bullet: anything in-flight that needs attention]
- [bullet: anything you're handling without me]

PATTERN: [optional — only if a behavioral pattern is relevant today]
```

No padding. No encouragement. Just signal.
