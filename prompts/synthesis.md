# END-OF-SESSION SYNTHESIS PROMPT

The session is ending. Write a synthesis to memory so tomorrow's brief has real signal.

## What to extract and store

1. **Quadrant progress** — what actually happened in each quadrant today
2. **Decisions made** — any choices, commitments, or directions set
3. **In-flight state** — what is in progress and where it stands
4. **People touched** — who was contacted, what the thread is now
5. **Patterns observed** — anything that fits a recurring behavioral pattern
6. **Startup state** — any pipeline movement, conversations, next steps

## What NOT to store

- Raw conversation text
- Completed tasks with no ongoing thread
- Anything that will be stale within 48 hours

## Format

Write structured entries to memory under these keys:
- `quadrant_state.[quadrant]` — updated state + score estimate
- `in_flight` — current open threads
- `people.[name]` — updated thread for each person touched
- `patterns` — any new or reinforced behavioral patterns
- `startup` — pipeline state

Be specific. Future-you is reading this at 9am before coffee.
